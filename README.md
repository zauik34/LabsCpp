# Лабораторная работа №1

**Тема:** обработка строки символов различными способами хранения.

Весь код находится в `main.cpp`: три функции для вариантов задания и `main()` с меню выбора.

## Задание и обработка

Подсчитать максимальное количество подряд идущих пробелов. Каждую отдельную серию пробелов обработать по её длине:

- если длина серии кратна 3, заменить всю серию одним символом `*`;
- иначе удалить эту серию.

Максимальная длина серии считается по исходной строке и выводится на экран. Условие кратности проверяется для **каждой серии отдельно**.

Пример (между буквами соответственно 3, 2 и 6 пробелов):

```text
Исходная строка: [A   B  C      D]
Максимальная серия: 6
Результат: [A*BC*D]
```

Обрабатываются обычные пробелы `' '`. Табуляция и остальные символы сохраняются. Квадратные скобки в консольном выводе показывают границы результата и не входят в строку.

## Три варианта

| Пункт меню | Функция | Хранение и ввод/вывод |
| --- | --- | --- |
| 1 | `processArray()` | `char[]` с отдельной длиной, без завершающего `\0`; ввод посимвольно, вывод через `fwrite()` |
| 2 | `processCString()` | Cи-строка с завершающим `\0`; чтение через `fgets()` |
| 3 | `processFile()` | Чтение первой строки `input.txt`, обработка как Cи-строки, запись в `output.txt` через `fopen()`, `fgets()`, `fputs()`, `fclose()` |

В каждой функции используется **только один исходный массив**. Индексы чтения и записи идут слева направо; индекс записи не обгоняет индекс чтения, поэтому необработанные символы не теряются. Дополнительных массивов, `std::string`, контейнеров и динамического выделения памяти нет.

Время обработки — `O(n)`, дополнительная память — `O(1)`. Максимальная длина входной строки — 4096 байт (для UTF-8 это может быть меньше 4096 символов). Слишком длинная строка отклоняется с ошибкой. Пустая строка и пустой файл дают пустой результат и максимум 0. В варианте 3 перевод строки не включается в результат; остальные строки файла не обрабатываются.

## Сборка и запуск

### Visual Studio 2022

Открыть **x64 Native Tools Command Prompt for VS 2022**, перейти в папку репозитория и выполнить:

```bat
cl /nologo /std:c++17 /W4 /EHsc /utf-8 main.cpp /Fe:lab1.exe
lab1.exe
```

Можно также создать консольный проект C++, добавить в него `main.cpp` и включить кодировку исходного и исполняемого наборов символов UTF-8 (`/utf-8`).

### GCC / Clang

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o lab1
./lab1
```

Для файлового варианта запустить программу из папки репозитория и выбрать пункт `3`. В репозиторий включён `input.txt` с примером `A   B  C      D` и соответствующий `output.txt` с результатом `A*BC*D`. Максимальная серия в примере — 6 пробелов.

Можно записать свою строку в `input.txt`. Файлы ищутся в **рабочей папке запуска программы**. Существующий `output.txt` перезаписывается. Для кириллицы использовать UTF-8 без BOM.

В `.gitignore` исключены сборочные файлы и настройки IDE. Файлы примера `input.txt` / `output.txt` хранятся в репозитории.

## Автоматические тесты

`tests.cpp` — отдельная программа с тестами на Catch2 2.13.10. Семь простых примеров проверяются во всех трёх режимах: замена серий из 3 и 6 пробелов одной `*`, удаление остальных серий, подсчёт максимума, пробелы по краям, пустая строка и строка без пробелов. В файловом режиме дополнительно проверяется содержимое выходного файла.

Служебные файлы тестов находятся в `build/test-data/`, которая исключена из Git. Примеры `input.txt` / `output.txt` в корне репозитория сохраняются. `main.cpp` и `tests.cpp` собираются в **разные исполняемые файлы**, поскольку у каждого есть собственный `main()`.

Catch2 уже включён в репозиторий: `catch2/catch.hpp`, лицензия — `catch2/LICENSE.txt`. Отдельно скачивать библиотеку или настраивать пути заголовков не требуется. При скачивании ZIP нужно распаковать всю папку проекта, сохранив папку `catch2` рядом с `tests.cpp`.

В **x64 Native Tools Command Prompt for VS 2022**, находясь в папке репозитория:

```bat
cl /nologo /std:c++17 /W4 /EHsc /utf-8 main.cpp /Fe:lab1.exe
cl /nologo /std:c++17 /W4 /EHsc /utf-8 tests.cpp /Fe:tests.exe
tests.exe
```

Для GCC / Clang в Linux или macOS:

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o lab1
g++ -std=c++17 -Wall -Wextra -Wpedantic tests.cpp -o tests
./tests
```

Исполняемые файлы исключены из Git. Для автозапуска в отдельном тестовом проекте Visual Studio можно указать `"$(TargetPath)"` в событии после сборки; рабочая папка запуска должна содержать `lab1.exe`.
